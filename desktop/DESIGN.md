# Framegrab UI

The main task is interval screenshots for AI reference. Open video / Download appear once in the header. With a source, show video, scrubber, editable timestamp, Every N sec slider and number, Whole video / Range, primary Sample N frames, individual Capture, subtitle track and Crop. Start/end fields appear only when Range is selected.

Whole video, two-second interval, native PNG and AI reference pack are the defaults. Downloads default to high (1080p) and embedded captions. Save shows the page/image/transcript count, then the completed output path and Open folder. Numbered pages hold four frames each; source images and complete caption text remain available separately.

Transcript, settings and commands stay in the overflow menu. IBM Plex Sans is bundled locally. The user's UI polish principles are applied: obvious primary action, useful density, readable controls, minimal copy, no slogans, empty sidebar, footer, ornamental cards, duplicate controls or tutorial paragraphs. Arc button/dialog/select components and attribution are preserved. Motion respects reduced-motion settings.
