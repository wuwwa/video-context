# Framegrab 2.1

Framegrab turns videos into captioned screenshots for ChatGPT, Codex, and other video-reference workflows.

- Open a local video or download a URL with built-in yt-dlp. Default: up to 1080p, English subtitles, automatic captions included, embedded subtitle track. Lower quality and best-available options are included.
- Sample every two seconds across the whole video by default. Change the interval with the slider or number field, or select a start/end range. Scrub or type a timestamp and Capture for individual frames.
- Save an AI reference pack: original-resolution PNGs, four-frame image pages, full available transcript, and a timestamp/source manifest. Save shows the actual folder with Open folder.
- Large exports create more pages instead of shrinking hundreds of frames into one image. A 300-frame export creates 75 pages. Available caption text is rendered into frames and repeated below page tiles.
- The portable ZIP includes the JSON command interface for agents. No separate Python, FFmpeg, Node, or yt-dlp installation is needed for the packaged app.

## Downloads

- **Framegrab.exe**: standalone Windows GUI.
- **Framegrab-Windows.zip**: GUI, agent CLI, documentation and licenses. Extract and open Framegrab.exe.
- **Framegrab-source.zip**: application source and build instructions.
- **SHA256SUMS.txt**: checksums for these downloads.

Requires Windows x64 with Microsoft Edge WebView2. Text subtitles are supported; bitmap subtitle OCR is not included. Captures remain temporary until saved. Some YouTube requests require verification or are rate-limited; the app reports that instead of claiming the download succeeded. Upload limits remain those of the AI service used afterward. The Windows executable is unsigned.

Verified: eleven FFmpeg/yt-dlp integration checks, a 301-frame export regression preserving original images byte-for-byte, interval/range GUI capture, packaged WebView2 download/capture/export, packaged agent commands, and responsive layouts. See desktop/VERIFICATION.md in the repository for scope and limitations.
